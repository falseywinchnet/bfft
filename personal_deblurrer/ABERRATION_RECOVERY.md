# Relative aberration recovery

The first aberration experiment asks a narrower and falsifiable question than
known-operator deblurring: can several observations of the same unknown scene
reveal their different lens transports when neither the clean scene nor any
operator is supplied to the estimator?

The answer is yes for the relative, locally affine second-moment field. A lens
component shared by every capture remains unidentifiable. The implementation
therefore calls this *relative aberration recovery* and exposes the common
component as a gauge instead of silently treating the least-blurred capture as
ground truth.

## Observation cancellation

For capture `i`, local Fourier charts obey

```text
Yi(w, x) = Hi(w, x) X(w, x).
```

Pair quotients cancel the unknown scene. Near the Fourier origin, the centered
positive transport has

```text
log |Hi(w, x)| - log |Hj(w, x)|
    = -1/2 w^T [Sigma_i(x) - Sigma_j(x)] w + O(|w|^4).
```

`multicapture_transport.py` closes these differences on the complete capture
graph and estimates one spatial covariance atlas per observation. It does not
classify radial, astigmatic, shear, or ghost blur. Fourier-circle support,
cross-observation closure, and the positive covariance cone determine the
direction that the data supports.

`aberration_recovery.py` then projects each measured covariance component onto
the complete quadratic coordinate jet

```text
[x^2, xy, y^2, x, y, 1].
```

This is the local second-moment form generated by affine lens transport. The
fit is diagnostic: reconstruction continues to use the more expressive raw
atlas, so the quadratic model cannot overwrite evidence that it fails to
explain. Checkerboard crossfit measures whether the jet predicts withheld
locations. A stationary-point candidate for the trace action is reported only
when its quadratic is definite, conditioned, and supported by the observed
raster; it is not presumed to be a lens center.

## Synthetic recovery battery

The M4 CPU battery uses all six denoiser sources at `96 x 96`, four captures,
64 positive-line passes, and clean truth only for terminal scoring. The
estimator receives only the four aberrated observations.

| observation law | best capture | average | recovered | raw/jet tensor correlation | jet crossfit |
| --- | ---: | ---: | ---: | ---: | ---: |
| radial + rotated astigmatism | 37.149 dB | 31.983 dB | 36.364 dB | 0.710 / 0.689 | 0.976 |
| radial + astigmatism + sparse ghost | 36.439 dB | 31.464 dB | 36.418 dB | 0.795 / 0.779 | 0.983 |
| relative field + common radial gauge | 31.437 dB | 29.380 dB | 31.568 dB | 0.718 / 0.697 | 0.976 |

The first two controls recover 4.38 dB and 4.95 dB over observation averaging.
In the ghost control the reconstruction nearly matches the best capture while
using every capture as a positive measure; no frame or family is selected.

The common-gauge control is the crucial negative result. The recovered image is
40.733 dB relative to the scene after the shared radial operator, but only
31.568 dB relative to the unavailable sharp scene. Thus the relative lens
field was removed while the common lens field remained. That is the exact
identifiability boundary predicted by the observation equations.

## Reproduce

```sh
/Users/ultimussecundai/.local/bin/m4build -- \
  python3 -m personal_deblurrer.run_aberration_recovery_benchmark \
  --size 96 --passes 64 \
  --out /tmp/personal_deblurrer_aberration_recovery
```

This experiment does not establish single-image blind aberration recovery,
higher-order chromatic aberration recovery, or removal of an aberration shared
by every exposure. Those require additional independent information rather
than a more aggressive inverse.

## Workbench

The **Relative lens-aberration recovery** panel in `workbench.py` provides the
same estimator interactively:

1. Load or synthesize at least three registered observations of one scene.
2. Check only those observations in the panel's explicit capture list.
3. Choose the desired output capture as the active source and run **Recover
   selected aberration (3+)**.

The result and uncertainty appear beside two diagnostic tabs per capture. The
raw relative atlas and quadratic jet use neutral gray for the common zero
gauge, red for relative trace, green for axis anisotropy, and blue for diagonal
coupling. A yellow cross appears only for an authority-gated stationary
candidate. The status line reports crossfit authority and repeats that common
lens transport is not identifiable.
