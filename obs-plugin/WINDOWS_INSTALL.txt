BFFT Cartoon for OBS Studio 32.1.x — Windows x64
=================================================

This build includes five display modes:

* Cartoon + texture
* Fine chrome
* Recursive recovery
* Layer interference
* Information caustics

The filter processes every source pixel at its original pitch. Its FACR
backend accepts an arbitrary length on one axis. If neither source axis is a
supported power-of-two length, the cheaper axis is extended with symmetric
reflection and the exact source rectangle is cropped afterward. There is no
work-resolution scaling or aspect distortion.

Install
-------

1. Close OBS Studio.
2. Open the OBS Studio installation directory. The default is:

       C:\Program Files\obs-studio

3. Copy the "obs-plugins" folder from this archive into that directory.
   Allow Windows to merge the folder.
4. Start OBS Studio.
5. Open a video source's Filters, add "BFFT Cartoon", and choose a display
   mode.

Fine chrome uses the one-step correction
cartoon - ROF(input - texture, shading_c), then renders that field as a
displaced chrome surface. Cartoon + texture exposes independent cartoon,
texture, and shading gains. Recursive recovery performs the useful two-stage
texture recovery directly, without an intervening 8-bit OBS round trip. Layer
interference displays the interaction between texture and the cartoon-side TV
defect.
Information caustics turns that information into a color-preserving refractive
field.

With Cartoon set exactly to zero, signed texture detail is shown
around neutral gray. Source chroma is removed in that view so empty regions
do not turn red.

The resulting DLL path should be:

    C:\Program Files\obs-studio\obs-plugins\64bit\bfft-cartoon.dll

Compatibility
-------------

* Windows 10 or 11, x64
* OBS Studio 32.1.x, x64
* No separate BFFT, MinGW, or Visual C++ runtime installation is required.

If OBS was running during installation, restart it before looking for the
filter.

Native-resolution processing is intentionally more expensive than the older
small surrogate grid. Start with 6 CPU threads and 8 TV effect sweeps. The
jump split is fixed-cost; this sweep control affects the ROF-based effects.
Recursive recovery performs two splits per frame and is the heaviest mode.

The periodic FACR backend now carries the new jump-measure cartoon on ordinary
video dimensions. Input aliases the cartoon output in place, recomposition
reuses that plane, and effect scratch is lazy, substantially reducing the
plugin's frame-buffer footprint.
