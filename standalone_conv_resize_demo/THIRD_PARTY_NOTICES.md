# Third-party method notices

The comparison labeled “AMD FSR 1.0 EASU” is an independent CPU transcription of the published FidelityFX FSR 1.0 EASU equations. RCAS is not included. The reference implementation and its license are maintained by AMD at <https://github.com/GPUOpen-Effects/FidelityFX-FSR>.

Scikit-image supplies the public demo rasters and carries its own licenses. Dear PyGui, NumPy, and Pillow are runtime dependencies and are not vendored in this directory.

No Airspy source code is included. See the provenance note in `README.md`.
